Arquitectura de la aplicación

Monorepo con un backend monolítico (FastAPI) y un frontend (Next.js). Un solo proceso de backend contiene colectores, base de datos, servicios y API; el modelo corre en un pool de procesos hijos solo para no competir por el GIL. Solo recomienda, no ejecuta transferencias.
